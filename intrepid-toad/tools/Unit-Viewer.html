Unit Stats Viewer Tool Information

What is this tool?

This is a design tool that allow you to compare statistics between role or the whole data set. This is useful to do when mathmatically balancing or optimising in game design.

How do i use this tool?

  1. Upload a valid .csv file
  2. Pick a key to generate a selectable list
  3. Select “unit” to populate the statistics table
  4. View statistics
