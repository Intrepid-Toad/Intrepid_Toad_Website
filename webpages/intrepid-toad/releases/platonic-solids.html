Origin

In unity you can only have 4x 3D objects with volume (Cube, Sphere, Cylinder, Capsule).

Adding the the 5x platonic solids (Fig.) allows for greater creativity. It also includes physics based dice rolls.

How to use

This tool is integrated well with unity, just add it the same way (Fig.) you would any other 3D object, and you will notice the platonic solids.

Be Creative

Feel free to distort and warp the platonic solids to make creative objects(Fig.,Fig.).

Natural Dice

This tool also include phyiscal based dice rolls (Fig.). We thought this would be a interesting addition, especially for Virtual Reality games where you can grab objects.

UV mapped / Textured

All platonic solids are UV mapped and have a dice texture which can be used a reference if you decide to assign a different texture for it.
